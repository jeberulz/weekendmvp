# Compose and review Leo’s private landing page

Use the pinned approved blueprint, brand kit and Iris’s answer. Write the primary promise using a concrete product example from those inputs. Pick a hero and signup layout supported by that art direction. Add optional sections only when each answers a different visitor question. The renderer fixes section order. Vary the weight of the opening, the form treatment, and the evidence shown within those boundaries. A primary CTA tells the visitor what happens at its target. A secondary link earns its place when a specific objection needs answering first. [Landing contract and cross-check](../../lib/workspace/contracts/artifacts.ts) · [Rendered sections](../../components/tenant-site/sections.tsx)

Review the actual private preview served to its owner. Record the business, version and pinned inputs, then inspect these points:

- At desktop and phone widths, read the first screen without scrolling. Can a visitor identify the offer and the action? Follow any secondary link to the evidence its label promises. Test 320 CSS pixel reflow, enlarged text, long names and headings.
- Wait for fonts and media to settle before screenshots. Inspect the loaded type pair, focal crop or product plate, copy contrast, button boundaries, visible keyboard focus, heading order and accessible names. Check reduced motion. Compare with a different fixture brand and name one material difference that survives grayscale.
- Activate the primary CTA by keyboard, reach the correct form and submit a synthetic address such as `layout@example.test` using the private test action. Verify the test receipt for this version after refresh. Replay the same submission ID to check that a retry preserves the receipt and count. Capture the result inside the owner preview. Keep publishing and live lead collection under their own approvals.
- Record a pass or a concrete defect with viewport, component, expected and actual result. Fix within the brief and inspect again. Report the specific parts still unverified if the preview, an asset or a backend receipt is unavailable.

**Return to the lead** the saved draft version, a sentence explaining the composition and CTA choices, the owner’s preview destination and observed QA results. Distinguish schema acceptance, visual review and functional verification.
