## The Problem

AI automation agencies are drowning in tabs. A typical shop managing 10–20 clients runs Make scenarios, n8n workflows, and Zapier zaps across separate dashboards — each with its own login, execution log, and error notification channel. The agency owner opens five browser windows every morning just to answer one question: did anything break overnight?

The pain compounds as agencies scale. A freelancer with three clients can eyeball each scenario. At 15 clients, nobody has a portfolio view. Failed executions get buried in per-platform inboxes. Client onboarding means manually cloning scenarios, updating webhook URLs, and praying nothing was missed. When a client asks "what did we automate this month?" the agency exports CSVs from three tools and spends an hour building a slide deck.

Churn follows weak ROI proof. Clients pay $2,000–$5,000 per month for automation retainers but see only the output — a Slack message, a CRM update — not the 400 executions that ran cleanly or the 12 hours of manual work eliminated. Without a white-label dashboard showing uptime, volume, and dollar savings, clients downgrade to "we'll pause for now" and never come back.

Agencies also lack template infrastructure. Every new client starts from scratch: rebuild the lead-capture workflow, reconfigure the CRM sync, rewrite the error-handling logic. There's no deploy-from-template flow, no version control across client instances, and no way to push a fix to all clients running the same automation pattern.

The market is moving fast. AI agent platforms promise end-to-end automation, but agencies already invested in Make and n8n don't want to rip and replace. They need an ops layer — a ClientStack — that sits above the tools they use today and gives them portfolio visibility, client-facing ROI proof, and repeatable deployment.

## The Solution

ClientStack is a white-label operations dashboard for AI automation agencies managing 5–30 clients. Connect Make, n8n, and Zapier accounts once; monitor every execution, error, and scenario from a single pane. Deploy pre-built automation templates to new clients in minutes. Generate branded ROI reports that prove value before renewal conversations.

Agencies get portfolio health at a glance: green/yellow/red status per client, error rate trends, execution volume, and estimated time saved. Clients get a read-only portal showing their automations running, uptime percentage, and monthly impact metrics — without seeing Make's interface or your internal tooling.

**How it works:**

1. **Connect platforms** — OAuth into Make, n8n, and Zapier; map each client to their scenario bundles and workspace IDs
2. **Monitor portfolio** — Unified execution feed, error alerts, and per-client health scores across all connected platforms
3. **Deploy templates** — One-click clone of agency-tested workflows (lead routing, CRM sync, invoice reminders) into a new client's connected accounts
4. **Prove ROI** — Auto-generated white-label reports with execution counts, uptime, time-saved estimates, and AI-written narrative summaries
5. **Retain clients** — Scheduled monthly reports emailed to clients; churn-risk alerts when execution volume drops or errors spike

## Competitive Landscape

Automation platforms own execution; CRMs own client relationships. Nobody owns the agency ops layer connecting both across multiple execution engines.

- **Make (Integromat)** — Visual automation builder with strong agency adoption. Pricing is operations-based: Free (1,000 ops/mo) → Core $9/mo (10K ops) → Pro $16/mo (10K ops + premium apps) → Teams $29/mo → Enterprise custom. Strong execution engine, zero portfolio view across clients, no white-label reporting, no template deploy to client accounts.
- **n8n** — Open-source workflow automation with growing agency use. Self-hosted free; Cloud Starter ~$20/mo (2,500 executions) → Pro ~$50/mo (10K executions) → Enterprise custom. Technical agencies love the flexibility; no client-facing dashboard, no cross-client monitoring, no ROI narrative generation.
- **Zapier** — Largest automation platform by user count. Task-based pricing: Free (100 tasks/mo) → Professional $19.99/mo (750 tasks) → Team $69/mo (2K tasks) → Enterprise custom. Agencies use it for simpler client workflows; same gap — per-account silos, no agency portfolio layer, no template deployment across client workspaces.
- **GoHighLevel** — Agency CRM and white-label platform. Pricing ~$97/mo (Starter) → ~$297/mo (Agency Unlimited) → ~$497/mo (SaaS Pro). Owns client management and white-label sites but doesn't connect to Make/n8n/Zapier execution data; agencies still tab-switch for automation health.
- **Horizontal AI agent platforms (Relevance AI, Stack AI, Gumloop)** — Usage-based pricing, typically $20–$500/mo depending on agent runs and seats. Compete on building AI agents from scratch; agencies already running Make/n8n don't want migration. These platforms lack multi-client ops monitoring for existing automation stacks.

**Your Opportunity**

Build the ops layer, not another automation engine. Agencies won't leave Make — they'll pay for a dashboard that makes Make manageable at 20 clients. White-label ROI reports solve the churn problem directly. Template deploy turns onboarding from days to hours. Price at $99–$499/mo — below GoHighLevel's ceiling, above a single Make subscription — and the math works on one saved client per year.

## Business Model

Agency SaaS with a value ladder that captures freelancers upgrading to shops and shops upgrading to enterprise.

- **Free guide + waitlist** ($0) — "Agency Automation Ops Playbook" PDF; email capture for launch list; builds SEO and trust before product exists
- **Starter trial** ($50/mo, first 30 days) — Connect up to 3 clients, basic execution monitoring, 1 platform integration (Make OR n8n OR Zapier)
- **Pro** ($250/mo) — Up to 15 clients, all three platform integrations, white-label client portal, monthly ROI report generation, template library (5 starter templates)
- **Agency** ($499/mo) — Up to 30 clients, unlimited templates, custom branding, team seats (3 included), priority support, churn-risk alerts
- **Analytics add-on** (+$99/mo) — Advanced dashboards, execution cost tracking per client, benchmark comparisons, export to Looker/Metabase
- **Enterprise** ($10K+/yr) — Unlimited clients, SSO, dedicated onboarding, custom integrations, SLA, annual contract

**Unit Economics (illustrative)**

- **$15–40/mo** — Infrastructure cost per agency (API polling, report generation, storage)
- **~75%** — Gross margin at Pro tier
- **$200–400** — Target CAC via agency communities, YouTube, and Make/n8n partner directories
- **120%+** — Net retention target (agencies add clients → upgrade tiers)

Target path: 50 Pro agencies at $250/mo = $12.5K MRR within 12 months. Upsell 20% to Agency ($499) and 10% to analytics add-on for blended ARPU above $300.

## Recommended Tech Stack

This is a multi-tenant dashboard with heavy API integration and periodic report generation. Ship Next.js for the app shell, Convex or Supabase for real-time execution feeds, and background jobs for polling Make/n8n/Zapier APIs.

- **Next.js (App Router) + Tailwind** — Agency dashboard, client portal (read-only subdomain or path), landing page with value-ladder CTAs. Server components for dashboard shells; client components for live execution feeds.
- **Convex or Supabase** — Multi-tenant data: agencies, clients, platform connections (encrypted OAuth tokens), execution logs, error events, report history. Convex gives real-time subscriptions on execution feeds; Supabase gives mature RLS for tenant isolation.
- **Stripe Billing** — Subscription tiers ($50 trial → $250 Pro → $499 Agency), analytics add-on as second subscription item, enterprise invoicing via Stripe Invoicing.
- **Make API + n8n API + Zapier API** — OAuth connection flows; webhook receivers for real-time execution events where supported; polling fallback (every 5 min) for platforms without webhooks. Normalize execution payloads into a shared schema (status, timestamp, scenario name, client ID, error message).
- **Claude (Anthropic API)** — Generate ROI report narratives from execution stats: "This month your automations processed 1,247 leads, saved an estimated 38 hours, and maintained 99.2% uptime." Prompt with structured JSON input; output markdown for PDF/email rendering.
- **React-PDF or Puppeteer** — Render white-label PDF reports with agency logo, client name, and AI narrative. Email via Resend or Postmark on a monthly cron.
- **Vercel + Cron** — Host Next.js; Vercel Cron or Inngest for scheduled polling, report generation, and churn-risk scans (execution volume drop greater than 30% week-over-week).

**2. Core Feature**

