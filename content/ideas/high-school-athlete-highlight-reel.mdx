## The Problem

Recruiting still runs on a two-minute tape. Parents pay $500–$2,000 for a local editor to hand-cut a season. Ideabrowser's community pull: about 500,000 families in that spend band, and 74% of parents in the Reddit sample said they would use a cheaper automatic reel. r/YouthSports (50k) is full of "does anyone know an editor who won't take six weeks." r/VideoEditing (248k) is the supply side — freelancers who do not want another $150 soccer job.

Hudl already sits on 14 million-plus users. They can ship native AI tomorrow. That is the existential risk, not Magisto. Until they do, the tape is still a dad with a phone on a stick and a weekend in Premiere.

Soccer first. The field is a rectangle, the ball is a high-contrast object, and club culture already shares Hudl links. Football and basketball come after the first 200 paying families.

## The Solution

Upload the game. Get a 90-second reel with the touches that look like recruiting film — not a random "best moments" montage with stock music. $29 a reel or $149 a season in the one-liner; the ladder that actually matches weekend-MVP math is a free first game, then $15/month unlimited or $5–$15 per game.

**How it works:**

1. **Ingest** — Parent or coach drops a 90-minute file or a YouTube/Hudl URL. Jersey number + team color are required. No "we'll figure out who you are."
2. **Detect + rank** — Player tracking + ball events (shots, take-ons, saves). Rank clips by coach-shaped rules: successful action + camera stability + duration, not just "fast motion."
3. **Reel + share** — 60–120 second cut, captions, a clean end card with grad year and position. One-tap share to Hudl, X, and the club group chat. Season pass concatenates across games.

## Competitive Landscape

- **Magisto (Vimeo)** — from $4.99/month. Generic auto-edit. No jersey lock.
- **Splice** — about $4.99/month. Mobile cuts for creators, not recruiting film.
- **Filmora** — free + subscription / perpetual. Template highlight maker. Parent still picks the clips.
- **InVideo** — free limited, paid for watermark-off. Same template problem.
- **Hudl** — team subscriptions. The platform of record. No consumer "make my kid's reel tonight" SKU that is good.
- **Premiere Rush / Canva Video** — manual substitutes. This is what the $500 editor is replacing.

**Your Opportunity**

Free "how coaches read a tape" guide → first game free → $15/month unlimited or $5–$15/game → $12/month annual → $500+/season custom (human cleanup, music rights, multiple positions). Magisto will not add jersey ID. Hudl might — so your brand has to be "the recruiting reel," not "AI video."

Unit economics:

- GPU / API per 90-minute 1080p ingest: budget $1–$3; price the per-game SKU at $9 to stay 3x
- Season $15/month only works if most families upload 2–4 games, not 40
- Club coach as the multiplier: one coach, 18 families

Do not build a marketplace for editors. That is the $500 problem you are deleting.

## Recommended Tech Stack

- **App:** Next.js 15 + a Python worker (Modal or Fly) for the model
- **Auth / billing:** Clerk + Stripe ($15 sub + per-game checkout)
- **Storage:** Mux or Cloudflare Stream for ingest + playback
- **DB:** Supabase — `athletes`, `games`, `clips`, `reels`
- **Models:** off-the-shelf player tracking (e.g. RF-DETR / ByteTrack) + a ball detector; Claude only for the end-card copy
- **Share:** Hudl link paste + native MP4 download

**1. Project Setup**

```text
Build the weekend MVP of "Highlight Reel": a parent uploads a game film, marks the plays that matter and shares a short reel page that plays them in order, with a clean end card. Marking is manual this weekend. This handles a minor's video, so the parent owns everything and links are private.

Stack: Next.js (App Router, TypeScript), Tailwind, Supabase (Postgres, Row Level Security, Auth with email magic link for the parent), Mux for upload and playback. The reel is an ordered playlist of clips that plays back to back. Deploy on Vercel.

Tables (Row Level Security on, a parent reads only their own rows; the share page reads through a server route that checks the token):
- athletes(id, user_id, display_name, jersey, team_color, grad_year, position, contact_email)
- games(id, athlete_id, opponent, played_on, mux_asset_id, mux_playback_id, duration_sec)
- clips(id, game_id, start_sec, end_sec, label, note, selected boolean, position)
- reels(id, athlete_id, title, share_token, expires_at, clip_order jsonb, created_at)

Screens: /login, /athletes, /games/[id] (the player and the marking tools), /reels/[id] (order and preview), /r/[token] (the public reel).
Env vars (names only): NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_ANON_KEY, SUPABASE_SERVICE_ROLE_KEY (server only), MUX_TOKEN_ID, MUX_TOKEN_SECRET.

Do not build: billing, per-game or season pricing, player or ball tracking, automatic clip ranking, a stitched MP4 download, a social feed, other users' accounts.
Done when: npm run dev starts, you can sign in, and the four tables exist with Row Level Security on.
```

**2. Core Feature**

```text
Build the one feature that proves Highlight Reel: a parent turns 90 minutes of film into a 90-second reel without an editor.
1. A parent creates an athlete with a jersey number, team color, graduation year, position and an optional contact email. Collect nothing else about the child.
2. Upload a game file through Mux direct upload, with a progress bar and a note that large files take a while. Save the asset and playback ids.
3. The game page plays the film with keyboard marking: press one key to mark the start of a play and another to mark its end. Each mark saves a clip with a label and a note and shows it in a list that jumps to that moment when clicked.
4. The parent picks the clips to keep and drags them into order. The reel page shows the total length and warns when it is over 120 seconds.
5. The public reel at /r/[token] plays the selected clips back to back with a short pause between them, using each clip's start and end, then shows an end card with the athlete's name, position, graduation year and contact email if the parent added one.
6. Make the token unguessable, set the page to noindex, expire the link after 90 days by default and let the parent turn it off at any time.
7. Add a Delete athlete button that removes the games, clips, reels and the Mux assets.
Rules: only the parent can see the game film. The public page shows only the selected clips. Never show a child's full name unless the parent typed it for the end card.
Empty state: with no games, show the upload box and the keys for marking plays.
Done when: a sample game uploads and plays, marking three plays creates three clips, the public link plays them in order with the end card and works without a login, an expired or disabled link shows a clear message and Delete removes the Mux assets.
```
