## The Problem

Most small businesses do not run on one system. They run on a dozen. Invoices move through one platform, customer records live in a CRM someone set up two years ago, project updates travel by email, and the "source of truth" is whichever spreadsheet the owner opened last. Every one of those handoffs is a place where information gets re-keyed, dropped, or delayed. Owners keep hearing that automation will save them money, and they believe it, but they freeze at the exact same question: which process is actually worth fixing first?

That freeze is expensive. The default answer today is to hire a consultant, and a workflow or automation specialist will happily charge anywhere from about $500 to $3,000 for a discovery engagement, with deeper audits running to $5,000 or more. Worse, half of that engagement is spent on documentation the owner could have provided themselves: listing the tools in use, describing where data passes between them, and flagging which tasks eat the most hours. The owner pays premium consulting rates for note-taking before any real automation gets built.

The community evidence is loud and specific. Reddit's r/automation has grown past 214,000 members, r/n8n past 243,000, and r/businessanalysis past 126,000, and the recurring theme across all of them is not "how do I build a Zapier zap" but "where do I even start." One widely referenced warning in these threads captures the fear perfectly: people who try to replace entire departments with Zapier learn the hard way that they needed a clear map first. On the process side, business analysts openly vent that mapping is messy, stakeholder buy-in is hard, and the maps rarely connect to a dollar figure anyone cares about. Meanwhile "process mapping tool" pulls roughly 40,000 searches a month, and terms like "workflow automation tools" and "ai workflow automation" are climbing fast with high commercial intent. The demand is already routed; nobody has built the front door.

## The Solution

Firstflow is a guided workflow audit that a nontechnical owner can finish in a single sitting. Instead of a blank diagramming canvas, it runs a structured interview: it asks which platforms you use, where information passes from one tool to the next, and which tasks consume the most hours each week. Owners can paste a list of their software, connect a few accounts, or narrate a screen share, and a language model turns that raw input into a clean, readable operations map — every handoff, every data flow, drawn without the owner ever touching a flowchart tool.

The map is only half the value. The other half is the ranking. Firstflow scores each candidate process on ROI, risk, and complexity, then hands back a prioritized shortlist: automate this first, here is why, here is the rough time saved, here is the data sensitivity to watch. The final output is an execution brief clean enough to hand straight to a specialist or agency — turning a $3,000 discovery engagement into a repeatable, standardized diagnostic. Diagnosis before execution, in one session.

**How it works:**

1. **Describe your stack** — The owner pastes a software list, connects a few accounts, or shares a screen while narrating a typical week; the guided prompts capture platforms, handoffs, and time-heavy tasks.
2. **Generate the map** — A language model parses the input and renders a visual operations map showing every tool, handoff, and data flow, with sensitive data (payments, customer PII) labeled automatically.
3. **Rank the opportunities** — Each process is scored on ROI, risk, and complexity to produce an ordered shortlist of what to automate first and what to leave alone for now.
4. **Export the brief** — The owner downloads a PDF map plus an agency-ready execution brief, or pushes the shortlist toward Zapier, Make, or n8n as a starting blueprint.

## Competitive Landscape

The category is crowded with execution tools and generic diagramming apps, but almost nobody sells a standardized, SMB-first automation-readiness audit. Every "competitor" is either too manual, too complex, or a bespoke human service.

- **Lucidchart / Lucid** — Best-in-class visual diagramming with strong process-mapping templates. Freemium, with individual plans around $8 per month and team plans around $9 per user per month. But it is a blank canvas: no automation ROI ranking, no "what to fix first" logic, and it assumes the user already knows how to map a process.
- **Miro / Mural** — Collaborative whiteboards with journey-mapping and process templates. Free tier, with paid seats from roughly $8 to $16 per user per month. Great for a workshop with a facilitator; useless for a time-poor owner who needs a self-serve diagnosis, and it has no scoring engine at all.
- **Process Street / SweetProcess / Trainual** — SOP and checklist tools that speak SMB language. Process Street team plans start around $100 per month, SweetProcess runs about $99 per month, and Trainual plans start near $249 per month. They solve "how do we run this consistently," not "what should we automate first and why" — no stack analysis, no ROI shortlist.
- **Kissflow / Nintex / Creatio** — Low-code BPA platforms with some process discovery. Pricing is sales-led and enterprise-grade, with Kissflow starting around $1,500 per month. Far too heavy and expensive for a nontechnical micro-business, and discovery modules assume IT involvement and event logs the owner does not have.
- **Zapier / Make / n8n plus automation agencies** — The execution layer itself (Zapier free to about $19.99 per month and up; Make from about $9 per month; n8n free to self-host) and the consultants who wire it together. Agencies bundle their own audits into $500 to $5,000 engagements. This is the real competition, and it is exactly the manual, expensive step Firstflow productizes and undercuts.

**Your Opportunity**

No incumbent wants to be the neutral referee. Zapier and Make are incentivized to tell you to automate more, not to tell you what to skip. Diagramming tools will not add an opinionated ROI engine because their whole pitch is "flexible blank canvas." Agencies differentiate on their discovery process, so they will not standardize it away. That leaves a clean lane: a tool-agnostic, ROI-driven, 10-to-15-minute audit that owns the phrase "automation readiness," produces a consultant-ready brief for a fraction of consulting cost, and becomes the default pre-sales diagnostic that agencies, accountants, and MSPs run on every new lead.

## Business Model

Firstflow uses a diagnostic-to-subscription ladder: a cheap one-time audit gets an owner in the door, and ongoing ROI tracking plus re-audits keep them paying. This mirrors proven "diagnose then monitor" models in SEO, security, and observability, where the audit is the wedge and the monitoring is the recurring revenue.

- **Starter Map** ($99 one-time) — A single guided audit: visual operations map, ROI-ranked shortlist, and a downloadable PDF brief. The low-friction diagnostic that proves value in one session.
- **Growth** ($299 per month) — Ongoing audit access, re-mapping as the stack changes, ROI tracking against completed automations, benchmark scoring by vertical, and export to Zapier, Make, and n8n blueprints.
- **Agency / White-label** ($499 per month or per-audit rev-share) — Branded audits agencies run on every lead, shared client roster, and API access. This is the distribution flywheel: every audit an agency runs is a qualified referral for execution work.

**Unit Economics (illustrative)**

- **$0.20 to $0.80** — Language-model cost per completed audit, kept low by templating the interview and caching common patterns.
- **about 85%** — Gross margin on the recurring Growth tier once inference and hosting are covered.
- **$40 to $90** — Target blended CAC via SEO and community-led growth rather than paid acquisition.
- **$10k MRR path** — Roughly 34 Growth subscribers, or a blend of about 20 Growth subs plus 10 agency accounts and a steady trickle of $99 Starter Maps. Achievable inside the first cohort of operators pulled from Reddit automation threads.

## Recommended Tech Stack

The hard parts are not the diagram rendering; they are reliable stack parsing, an explainable scoring model, and export connectors that make the output actionable. Keep the surface small and the scoring transparent.

- **Next.js 14 + Vercel** — App Router for the guided-input flow and the dashboard, Edge functions for the audit endpoint, and Vercel Cron for scheduled re-audits and benchmark refreshes.
- **Supabase (Auth + Postgres)** — Tables for owners, audits, mapped nodes and edges, scored opportunities, and export artifacts. Row-level security is non-negotiable because owners are describing their real operations and customer data.
- **OpenAI gpt-4o-mini plus a reasoning model for scoring** — A cheap model parses free-form descriptions and screen-share transcripts into a structured graph; a stronger model produces the ROI, risk, and complexity scores with a short natural-language justification for each ranked item.
- **React Flow (or Mermaid) for rendering** — Turn the parsed graph into an interactive, exportable operations map without building a diagram engine from scratch.
- **Stripe Billing** — Starter Map one-time charge, Growth subscription, and the Agency white-label plan, with a customer portal for self-serve upgrades and per-audit metering for partners.
- **Export connectors** — PDF generation for the brief plus lightweight blueprint exports to Zapier, Make, and n8n so the audit feeds directly into execution and earns partner integrations.

## AI Prompts to Build This

Copy and paste these into Claude, Cursor, or your favorite AI tool.

**1. Project Setup**

```text
Create a new Next.js 14 (App Router, TypeScript, Tailwind) project called "Firstflow,"
an automation-readiness audit tool for small businesses. Provision Supabase with these tables:
owners (id, email, business_name, vertical, plan default 'starter'),
audits (id, owner_id, status, created_at),
nodes (id, audit_id, label, tool_name, data_sensitivity),
edges (id, audit_id, from_node, to_node, handoff_type, is_manual boolean),
opportunities (id, audit_id, title, roi_score int, risk_score int, complexity_score int, rationale text).
Enable row-level security so each owner only reads their own audits.
Add Stripe with three products: Starter Map ($99 one-time), Growth ($299/mo), Agency ($499/mo).
Set env vars OPENAI_API_KEY, plus Stripe and Supabase keys. Install the Vercel AI SDK and React Flow.
```

**2. Core Feature — Parse and Score**

```text
Build POST /api/audit as a Vercel function. Input: a free-form description of a small
business's tools, handoffs, and time-heavy tasks (typed, pasted list, or screen-share transcript).
Step 1: call gpt-4o-mini with a strict JSON schema to extract nodes (tools/systems),
edges (handoffs, marked manual or automated), and data_sensitivity labels (none, PII, payments).
Step 2: call a reasoning model to score each candidate automation on roi_score, risk_score, and
complexity_score (each 1-10) and return a one-sentence rationale explaining the ranking.
Persist everything to Supabase and return the graph plus an ROI-ranked shortlist ordered by
(roi_score minus risk_score minus complexity_score). Keep responses under a few seconds.
```

**3. Map Rendering and Export Brief**

```text
Build a dashboard page that renders the audit graph with React Flow: tools as nodes, handoffs
as edges, manual handoffs styled in a warning color, and data-sensitive flows badged.
Below the map, show the ranked automation shortlist as cards with the score breakdown and rationale.
Add an "Export brief" button that generates a PDF containing: the map image, the prioritized list,
estimated hours saved per item, and a data-sensitivity summary — formatted as an agency-ready
execution brief. Add a secondary export that emits a starter Zapier/Make/n8n blueprint for the
top-ranked opportunity.
```
