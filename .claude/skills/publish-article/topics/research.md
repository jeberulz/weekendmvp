## Ship checklist for each topic

1. Write `content/articles/{slug}.mdx` (frontmatter + body; FAQ questions verbatim in body; 3+ CTAs to `/startup-ideas`; no H1)
2. Append `articles/manifest.json` with `og.subject` / `og.accent` / `og.status: pending`
3. Hub → article links on matching `/build-with/*` and `/ideas-for/*`
4. `npm run og:generate -- --slug {slug} --surface article --non-blocking`
5. Commit + PR (do not merge without John)
6. **Post-merge (John):** `npm run seed:convex -- --only articles --prod`
7. Mark topic PUBLISHED here
