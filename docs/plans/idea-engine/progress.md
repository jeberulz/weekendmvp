## Phase 2 notes

Shipped `scripts/audit-idea-mdx.mjs`, the shared section spec at
`scripts/lib/idea-sections.mjs` (imported by `extract-idea-bodies.mjs` so the
regexes cannot drift), `ideas/audit-baseline.json`, a rewritten
`ideas/SECTIONS.md`, and both `validate:idea-tags` and `audit:idea -- --all`
wired into `.github/workflows/ci.yml`.

Four decisions the plan did not anticipate, each forced by the corpus:

1. **`## Sources` versus `ai-code-reviewer`.** The plan requires Sources as the
   eighth heading *and* requires `--slug ai-code-reviewer` to exit 0. That page
   has no Sources section; 20 of 185 pages don't. Resolved with
   `ideas/audit-baseline.json`: a generated, committed record of pre-auditor
   structural debt (32 pages), where a listed slug is exempt from exactly the
   checks named for it. `--all` is therefore a live gate for new pages instead
   of being permanently red and ignored, and `--strict` still reports the true
   contract. Regenerate with `audit:idea -- --all --write-baseline`; never add
   a new page to it.
2. **Citations are counted as URLs, not markdown links.** The plan says "at
   least two markdown links under Sources". Much of the corpus writes real
   citations as bare trailing URLs (e.g. `ai-agency-automation-control-panel`).
   Counting either form measures what the check is actually for. Matches phase
   3's own wording, "citation URL count".
3. **Placeholder and JSX checks run on prose only.** `{{client_name}}` inside a
   fenced AI prompt is content, not an unreplaced placeholder — three pages hit
   this. Likewise `\<` and `\{` are the correct MDX escapes and must not be
   flagged; honouring them takes the JSX-trap count across the corpus from a
   bogus 11 to a true 0.
4. **Bars set from the corpus, not invented.** 3 HowTo steps and 3 named
   competitors are the observed minimums across all 185 pages, and match the
   skill's existing STOP rule. Word count stays the specified 800.

Recorded debt at baseline time: 20 pages missing Sources, 15 under 800 words of
prose, 4 missing the `**How it works:**` list. `audit:idea -- --all --strict`
prints the current list.

## Phase 3 notes

`engine/eval/gold.json` is generated by `npm run engine:eval -- --write` from
the auditor, never hand-typed. Each entry stores the four counts plus the set of
checks the page passes today, so a check flipping pass → fail is a regression
even when every count holds. `ai-code-reviewer`'s missing Sources is recorded
honestly as not-passing rather than papered over — the engine has to beat what
shipped, not match its gaps.

Counts are a floor: a compiled page may exceed them, never fall below.
