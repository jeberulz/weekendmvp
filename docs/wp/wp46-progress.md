Fixture/draft records, altered figures, swapped evidence links and invalid metadata are refused. Secondary price sources are classified as `other`, not mislabeled as vendor pages.

The dry-run-first operator command is `npm run editorial:submit-engine -- --slug=SLUG`; apply requires exact hash, deployment, key and backup path.

Placeholder-policy checks are dropped. The settings page reports the engine and policy connected while release readiness remains unavailable until E6.
